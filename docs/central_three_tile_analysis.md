# 86장 세그멘테이션 이미지의 중앙 3개 타일 추출 분석

작성일: 2026-10-01

후속 변경: 학습용 타일 및 중앙 P1·P2·P3 추출을 ROI 중심선 기준으로 변경했다. [새 데이터셋과 학습 안내](roi_centered_training.md), [새 위치의 엑셀 재측정 분석](roi_centered_remeasurement.md)을 참고한다. DOE 엑셀의 현재 값은 새 ROI 중앙 기준이다. 아래는 기존 이미지 중앙 기준 분석과 당시 엑셀 반영 이력이다.

Label Studio의 `seg` 프로젝트에서 내보낸 이미지 86장을 대상으로, 256×256 타일 3개를 같은 기준으로 추출할 수 있는지 확인했다. 기존 중심 정렬 격자에서 **이미지 중심을 기준으로 가로로 붙어 있는 3개 타일**을 선택하면, 86장 모두 검은 바깥 영역 없이 추출할 수 있다. 실제로 이미지 타일 258개와 같은 좌표의 라벨 마스크 258개를 저장하고 원본 픽셀과 일치하는지 검증했다.

## 중앙 3개를 선택하는 기준

이미지 중심은 `(1023, 1023)`이다. 중앙 타일의 중심을 이미지 중심에 맞추고, 왼쪽과 오른쪽에 각각 타일 1개씩 붙인다. 기존 격자의 `(행, 열)` 좌표로는 `(0, -1)`, `(0, 0)`, `(0, +1)`에 해당한다.

아래 좌표는 0부터 시작하고 끝값을 포함하지 않는 반개구간이다. NumPy의 `image[y0:y1, x0:x1]`과 같은 규칙이다.

| 위치 | x 시작 | x 끝 | y 시작 | y 끝 | 크기 |
| --- | ---: | ---: | ---: | ---: | --- |
| 왼쪽 | 639 | 895 | 895 | 1151 | 256×256 |
| 중앙 | 895 | 1151 | 895 | 1151 | 256×256 |
| 오른쪽 | 1151 | 1407 | 895 | 1151 | 256×256 |

전체 선택 영역은 가로 768픽셀, 세로 256픽셀이다. 타일 간 겹침, 회전, 리사이즈, 패딩을 적용하지 않는다. 선택 좌표는 이미지 크기만으로 결정하며 `Exposure` 라벨의 위치나 양을 사용하지 않는다.

```python
size = 256
h, w = image.shape[:2]
x_center = (w - size) // 2
y_center = (h - size) // 2

image_tiles = []
mask_tiles = []
for offset in (-size, 0, size):
    x = x_center + offset
    image_tiles.append(image[y_center:y_center + size, x:x + size])
    mask_tiles.append(mask[y_center:y_center + size, x:x + size])
```

## 네 가지 배치의 비교

이미지 중심과 기존 ROI 경계선에서 계산한 소재 중심을 각각 기준으로 가로·세로 배치를 비교했다. `검은 픽셀`은 저장된 ROI 이미지에서 값이 0인 픽셀을 의미한다.

| 중심 기준과 배치 | 3개 모두 검은 픽셀 없는 이미지 | 검은 픽셀 없는 타일 | 라벨이 포함된 타일 |
| --- | ---: | ---: | ---: |
| 이미지 중심, 가로 3개 | 86 / 86 | 258 / 258 | 258 / 258 |
| 이미지 중심, 세로 3개 | 19 / 86 | 191 / 258 | 258 / 258 |
| ROI 중심, 가로 3개 | 86 / 86 | 258 / 258 | 258 / 258 |
| ROI 중심, 세로 3개 | 84 / 86 | 255 / 258 | 258 / 258 |

기존 격자에서 같은 좌표로 추출하는 목적에는 **이미지 중심의 가로 3개**가 적합하다. 이미지 중심의 세로 3개는 67장에서 적어도 하나의 타일에 검은 영역이 포함된다.

소재 자체의 중앙을 측정하려면 다른 정의가 필요하다. 이 경우 이미지 중앙 열에서 ROI 위·아래 경계선의 중간을 y 중심으로 사용해야 한다. 저장된 경계선으로 계산한 ROI 중심은 이미지 중심에 비해 y 방향으로 최소 −50.88픽셀, 중앙값 +149.02픽셀, 최대 +276.76픽셀 차이가 있었다. 양수는 이미지 아래쪽이다. 기존 ROI 결과에는 86장 중 80장에 `needs_review` 표시가 있어, ROI 중심 비교를 소재 경계의 정답 검증으로 해석하지 않는다.

라벨 면적 비율은 `count(alpha > 0) / 65,536`으로 계산했다. 브러시 alpha에는 0과 255 사이의 중간값이 있으며, 저장한 마스크는 해당 값을 그대로 보존한다. 따라서 저장된 마스크를 이미 이진화된 마스크로 가정하면 안 된다.

중앙 3개만 선택하면 원래 이미지의 주변부는 제외된다. 이미지별 전체 라벨 픽셀 중 선택 영역에 남은 비율의 평균은 8.2398%, 범위는 2.8410–13.7292%다. 이 수치는 **함침율이 아니라 전체 라벨의 보존 비율**이다. 중앙 3개로 구한 면적 비율은 중앙 영역의 측정값으로 해석한다.

## 엑셀의 표면함침율과 연결

대상 파일은 `docs/260916_2세부_텐덤금형_사출실험_DOE_고정측20런_이동측4런.xlsx`다. `데이터 기록표`에는 실행순서·파팅면·샷별 P1·P2·P3 입력란이 있고, 평균과 범위는 기존 수식으로 계산된다.

### 확정된 계산식과 측정 방향

2026-10-01 사용자 확인에 따라 `Exposure`를 **미함침 영역**으로 해석한다. 함침율은 다음과 같다.

```text
미함침 픽셀 수 = count(alpha > 0)
타일당 전체 픽셀 수 = 256 × 256 = 65,536
표면함침율 (%) = 100 × (1 − 미함침 픽셀 수 / 65,536)
```

`000` 방향 이미지만 엑셀에 반영한다. P1은 왼쪽, P2는 중앙, P3는 오른쪽 타일이다. `180` 방향 18장은 이번 엑셀 집계에서 제외하며 `000` 방향과 합산하거나 평균하지 않는다. 따라서 86장 전체의 배치 검증과 엑셀에 들어가는 68장의 함침율 계산은 모집단이 다르다.

입력값은 기존 엑셀 양식에 맞춰 0–100 범위의 숫자로 저장한다. 예를 들어 93.2%는 `93.2`로 입력한다. 표시 자릿수는 기존 서식을 따르고, 계산에는 반올림 전 값을 사용한다. 원래의 `J열` 평균 및 `K열` 범위 수식을 유지한다. 범위의 단위는 %p다.

### 시편과 샷의 연결 방법

[매칭.xlsx](매칭.xlsx)의 `시편관리표`를 연결 기준으로 사용한다.

1. 이미지 폴더의 `case 번호`, `축`, `촬영 폴더 번호`를 매칭표의 `Case No.`, `축`, `시편 No.`에 연결한다.
2. 폴더의 `-이동축`은 이동측으로, 나머지는 고정측으로 해석한다.
3. 매칭표의 `고유번호 (#)`를 DOE 엑셀의 `샷` 번호로 연결한다.
4. DOE의 `실행순서`, `파팅면`, `샷`이 모두 맞는 행에 P1–P3를 기록한다.

촬영 폴더 순서를 엑셀 행 순서로 그대로 대응시키면 안 된다. 예를 들어 case01 고정측은 다음과 같이 연결된다.

| 촬영 폴더 | Label Studio 작업 | 매칭표 고유번호 | DOE 기록표 행 |
| --- | ---: | ---: | ---: |
| `case01/01/000` | 616 | 947 | 9 |
| `case01/02/000` | 617 | 943 | 7 |
| `case01/03/000` | 618 | 945 | 8 |

두 원본 파일에 불일치가 있었던 아래 연결은 사용자 확인을 반영했다. 이 작업에서는 DOE의 기존 샷 번호·무게와 매칭표 파일 자체를 수정하지 않고, 함침율 연결에만 보정을 적용했다.

| 시편 | 매칭표 번호 | 연결한 DOE 샷 | 처리 근거 |
| --- | ---: | ---: | --- |
| case11 고정측 시편 1 | 1083 | 1093 | 사용자 확인에 따라 같은 시편으로 연결 |
| case20 고정측 시편 1 | 1073 | 1173 | 사용자 확인에 따른 번호 오기 보정 |
| case20 고정측 시편 2 | 1075 | 1175 | 사용자 확인에 따른 번호 오기 보정 |
| case20 고정측 시편 3 | 1077 | 1177 | 사용자 확인에 따른 번호 오기 보정 |

case11 시편 1의 무게는 매칭표 76.81g, DOE 76.99g으로 서로 다르며 기존 값을 그대로 보존했다. 나머지 연결된 시편은 두 파일의 무게도 일치하는지 확인했다. 보정 및 연결 이력, 원본 파일 해시, 작업 번호, 타일별 미함침 픽셀 수와 계산값은 [계산 기록](../data/label_studio_exports/2026-10-01/central_three_analysis/impregnation_results.json)에 저장했다.
