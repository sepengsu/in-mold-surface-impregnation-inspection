# ROI 중앙 P1·P2·P3 재측정

> 이 문서는 중심 간격 256픽셀 당시의 기록이다. **현재 원본 엑셀은 [직사각형 ROI · 547픽셀 간격](rectangle_roi_training.md)으로 다시 수정했다.** 최신 시각화는 `analysis/p123_rectangle_roi/`에 있다.

2026-10-01. `docs/260916_2세부_텐덤금형_사출실험_DOE_고정측20런_이동측4런.xlsx` 원본의 측정값을 ROI 중심선 기준으로 수정했다. 라벨이 있는 68개 시편은 Exposure 정답 라벨을 사용하고, 정답 라벨이 없는 Case 16 시편 2(#1155)만 사용자 확인에 따라 기존 B 모델 예측값을 사용했다. 모두 000 방향이다.

## 측정 범위와 계산

ROI는 위·아래 경계의 중간선이다. 가로 중심 P2와 인접한 왼쪽 P1, 오른쪽 P3에서 각각 원래 해상도의 256×256 픽셀을 자른다. ROI 전체를 세 등분해 축소하는 방식은 아니다. 경계가 기울면 각 열의 중심선 높이에 따라 y 시작점이 달라진다. 전체 학습 타일도 같은 격자에 정렬했다.

```text
center_y(x) = (top(x) + bottom(x)) / 2
x0(P1, P2, P3) = (639, 895, 1151)
y0 = floor(center_y(x0 + 127.5) − 128)

Exposure 픽셀 수 = count(alpha > 0)
표면 함침율 (%) = 100 × (1 − Exposure 픽셀 수 / 65,536)
```

분모는 타일 한 장의 65,536픽셀이다. 전체 원본 2046×2046 면적을 분모로 사용하지 않았다. 각 타일은 ROI 기하 경계 안에 완전히 들어가며, 검정 마스킹 값 0은 없다. 소재 안의 어두운 회색 픽셀은 밝기만으로 제거하지 않는다. 자른 원본 이미지와 마스크를 같은 좌표로 직접 비교했고 회전·리사이즈·패딩을 적용하지 않았다.

시편별 새 좌표와 픽셀 수는 `outputs/measurements/roi_centered_20261001/label_measurements.json`에, 새 데이터셋 전체 좌표는 `data/label_studio_exports/2026-10-01/roi_centered_tiles_256/manifest.json`에 저장했다.

## 왜 대부분 90%를 넘는가

**주된 이유는 현재 정답 Exposure 라벨이 차지하는 면적이 작기 때문이다.** 라벨 68개 시편의 중앙 204개 타일에서 Exposure 면적 비율은 평균 4.2857%다. 정의대로 나머지 면적을 계산하면 함침율 평균은 95.7143%가 된다. 점 모양의 미함침 영역이 여러 개 보여도, 그 면적의 합이 전체 타일의 10% 미만이면 이 지표는 90%를 넘는다.

| 68개 라벨 시편 · 000 방향 | 결과 |
| --- | ---: |
| 중앙 204포인트 평균 | 95.7143% |
| 중앙값 | 96.5141% |
| 최솟값 / 최댓값 | 68.2404% / 98.9639% |
| 90% 초과 / 90% 이하 포인트 | 195개 / 9개 |
| 3포인트 평균이 90% 초과 / 이하인 시편 | 65개 / 3개 |

따라서 모든 값이 90% 이상이라는 해석은 맞지 않는다. 예를 들어 Case 1 고정측 시편 1(#947)의 P3는 Exposure 20,814픽셀로 함침율이 68.24%다. 반면 Case 4 이동측 시편 2의 P2는 Exposure가 679픽셀(약 1.04%)이라 함침율이 98.96%다.

### 측정 위치와 ROI 제외의 영향

| 측정 범위 | 함침율 |
| --- | ---: |
| 기존 이미지 중앙 3포인트, 204개 | 96.0681% |
| 새 ROI 중앙 3포인트, 204개 | 95.7143% |
| ROI 내부 전체 학습 타일, 000 방향 1,409개 | 95.1944% |
| 68개 영상의 전체 유효 ROI 픽셀 합계 | 94.6300% |

첫 두 행은 모든 타일의 면적이 같으므로 타일 평균과 전체 면적 비율이 같다. 마지막 행은 영상별 ROI 크기가 달라 전체 Exposure 픽셀 합계를 전체 유효 ROI 픽셀 합계로 나눈 면적 가중값이다. 시편별 전체 ROI 함침율의 단순 평균은 94.5756%로 조금 다르다.

ROI 중앙으로 옮기면서 평균은 0.3538%p 내려갔다. 개별 포인트 변화의 절댓값 평균은 0.7675%p이며, 가장 크게 내려간 값은 −9.9518%p다. 중앙 세 포인트가 전체 유효 ROI보다 약 1.08%p 높아, 위치와 가장자리 제외가 값에 영향을 주는 것도 확인된다. 다만 전체 유효 ROI에서도 94.63%이므로 중앙 선택만으로 높은 함침율을 전부 설명할 수 없다.

![분포와 범위 비교](../outputs/measurements/roi_centered_20261001/impregnation_analysis.png)

이 값은 **현재 Exposure 라벨 정의에 따른 표면 면적 지표**다. 라벨 밖의 픽셀을 모두 함침으로 취급하므로, 미함침 영역에 라벨이 빠졌다면 계산값은 높아진다. 이번 계산 검증만으로 라벨이 물리적인 미함침을 빠짐없이 포괄하는지까지 입증하지는 못한다. 또한 이 비율만으로 재료 내부나 부피 기준 함침율을 확정할 수는 없다.

기존 자동 ROI의 검토 필요 표시도 보존했다(86장 중 80장). 이번에 확인한 것은 저장된 경계에 따른 좌표·픽셀 일치이며, 경계를 수동으로 확정한 것은 아니다. 경계를 수정하면 타일 생성과 엑셀 측정을 같은 새 좌표로 함께 갱신해야 한다.
