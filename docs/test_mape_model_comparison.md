# 테스트 MAPE 기준 모델 비교

2026년 10월 1일 개선 비교의 A부터 D까지 네 모델을 동일한 테스트 데이터로 평가했다. 기존 A와 D 결과에 더해 B와 C의 저장된 체크포인트를 새로 추론했다. **전체 테스트 197장의 함침율 MAPE는 C가 가장 낮고, 실제 P1 P2 P3 용도인 000 방향 중앙 타일 27장에서는 B가 가장 낮다.**

## 테스트 비교 결과

| 모델 | 저장 epoch | 전체 테스트 MAPE | 중앙 000 테스트 MAPE | 전체 테스트 Dice |
| --- | ---: | ---: | ---: | ---: |
| A 기본 | 39 | 1.395236% | 0.772706% | 0.835019 |
| B 큰 영역 가중 추출 | 61 | 1.409768% | **0.762404%** | 0.834103 |
| C Tversky | 45 | **1.382109%** | 0.828973% | 0.837687 |
| D 두 방법 결합 | 57 | 1.398291% | 0.918411% | **0.838737** |

MAPE는 `100 × mean(abs(예측 함침율 − 정답 함침율) / 정답 함침율)`이며 단위는 %다. 실제 함침율 차이를 뜻하는 MAE의 %p와 구분한다. 모든 타일의 정답 함침율이 0보다 커서 제외한 표본이나 분모 보정은 없다. 모델 간 테스트 이미지와 라벨 해시, 순서, 정답 값이 동일하고, 모두 임계값 0.5의 전체 테스트 추론임을 확인했다.

전체 테스트의 순위는 C, A, D, B다. 중앙 타일 순위는 B, A, C, D다. 테스트는 case05, case10, case14의 197개 타일이며, 중앙 부분집합은 000 방향 9개 촬영의 3개 타일씩 총 27개다.

## 테스트 기준으로 사용할 후보

전체 내부 타일의 함침율 오차를 기준으로 고르면 **C의 45 epoch** 체크포인트다.

`D:\Code\vision_data\outputs\training\comparison_improvement_20261001_053043_365\C_tversky\best.pt`

기존 목표인 중앙 P1 P2 P3의 함침율만 기준으로 고르면 **B의 61 epoch** 체크포인트다.

`D:\Code\vision_data\outputs\training\comparison_improvement_20261001_053043_365\B_sampling\best.pt`

중앙 타일의 B와 A는 MAPE가 각각 0.7624%와 0.7727%로 매우 가깝다. B의 중앙 타일 최대 상대 오차는 2.2891%, A는 2.0467%라서 평균과 최악 사례의 순위는 같지 않다. 따라서 B가 모든 조건에서 확실히 우수하다고 판단할 수는 없다.

이 순위는 현재 저장된 네 best.pt 사이의 관측 결과다. best.pt 자체는 각 학습에서 검증 Dice로 저장되었으므로, 모든 epoch 중 테스트 MAPE가 가장 낮은 모델을 찾은 결과는 아니다. 테스트를 후보 선택에 사용했으므로 이 점수를 독립적인 최종 검증 성능으로 제시하지 않고, 독립 확인에는 새 case를 사용한다.

현재 자동 선택 파일은 원래 검증 Dice 기준으로 D를 가리킨다. B 또는 C를 사용할 때는 inference의 `-Checkpoint`에 위 경로를 명시해야 한다. 이번 비교에서는 자동 선택 파일이나 모델 가중치를 변경하지 않았다.
